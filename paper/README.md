# Papers

- **`ENTOLI_V3.docx`** — the working paper: the calculus, the durable machine
  and its theorems, authority at rest, the model-authorship study, and the
  evaluation. This is the canonical text.
- **`capsule-network.tex`** (+ `entoli.bib`, `capsule.bib`) — companion
  position paper: a network of mobile ENTOLI agents over attested hosts —
  checked on admission, authority-free in transit, resumed under local
  policy. Build with any LaTeX toolchain using the `acmart` class (e.g.
  Overleaf).

Evidence referenced by the papers lives in this repository: the crash-test
suite (`cargo test`), the authorship-study corpus
(`docs/convergence-study-2026-11-08/`), performance data
(`docs/bench-*.csv`), and the findings register (`docs/EVALUATION.md`).
